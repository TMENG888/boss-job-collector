# 岗位采集助手 (boss-job-collector)

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![Chrome](https://img.shields.io/badge/Chrome-Manifest%20V3-4285F4)](https://developer.chrome.com/docs/extensions/)
[![Platform](https://img.shields.io/badge/平台-BOSS直聘_|_实习僧-00bebc)](https://www.zhipin.com)

一个开源的 Chrome 扩展（Manifest V3），用于自动采集 **BOSS 直聘** 与 **实习僧** 搜索结果中的岗位数据：
逐屏增量采集、自动翻页、多关键词接力、薪资字体加密自动解密、JD 详情抓取，达到设定数量自动停止，一键导出 CSV。
**两平台可同时各自运行采集任务，互不干扰。**

> **⚠️ 免责声明**：本项目仅供个人求职与学习研究使用。使用前请阅读并遵守 BOSS 直聘《用户协议》；请控制采集频率与数量，请勿商用、勿转卖数据、勿用于任何违法违规用途。因使用本工具产生的一切后果由使用者自行承担，与作者无关。

## 功能特性

- **逐屏增量采集**：每滚动一小步就解析新卡片并上报，达到目标数量立即停止，不浪费一次滚动
- **自动翻页**：模拟点击"下一页"，翻页间隔随机（4~8s）模拟人工节奏；遇到滑块验证自动暂停等待人工完成后继续
- **多关键词接力**：关键词支持逗号分隔，某个搜索词采尽（BOSS 单词上限约 300 条）自动切换下一个；严格忠于关键词自身检索结果，不做变体扩展
- **薪资字体解密**：BOSS 用自定义字体把数字渲染成 PUA 乱码字符，插件通过 canvas 字形模板匹配自动还原真实数字
- **JD 详情抓取**：逐条获取职位描述全文、详情页薪资、福利标签、行业/规模/融资
- **失败自动重试**：抓取失败的岗位自动限次重试（最多 3 次）；一键"校验修复"清洗异常数据
- **CSV 导出**：带 BOM，Excel 直接打开不乱码
- **数据本地化**：所有数据仅存于浏览器 `chrome.storage.local`，不经任何第三方服务器

## 安装

1. 下载本仓库（`git clone` 或 Download ZIP 后解压）
2. 打开 Chrome / Edge，地址栏输入 `chrome://extensions`（Edge 为 `edge://extensions`）
3. 打开右上角（Edge 为左侧）的 **开发者模式**
4. 点击 **加载已解压的扩展程序**，选择本目录
5. 在浏览器登录 BOSS 直聘，点击工具栏中的插件图标开始使用

## 使用方法

1. 点击插件图标，填写：
   - **岗位关键词**：支持多个，中英文逗号/顿号分隔均可（如 `爬虫实习生，python实习`），采完一个自动接力下一个
   - **城市**：直接填城市名（如 `广州`，留空=全国），无需查代码；也可先在 BOSS 网页上搜好，勾选"采集当前已打开的搜索页"
   - **目标数量**：达到后自动停止；所有搜索词采尽仍未达标时自动收尾并补全 JD
   - **JD详情采集**：自动模拟真人点击进出详情页（一次一条，复用已登录标签页，最稳）
2. 点击 **开始采集**：自动打开搜索页 → 逐屏滚动读取 → 翻页等待期间穿插获取 JD → 某个搜索词采尽自动切换下一个
3. 采集完成后自动进入 JD 补全阶段；随时可点 **补全JD** 补齐、**校验修复** 清洗异常值
4. 点 **导出CSV** 保存数据

## 采集字段

岗位名称、薪资（详情页薪资自动并入）、城市/区域、经验要求、学历要求、技能标签、福利标签、公司名称、所属行业、公司规模、融资阶段、JD职位描述、职位链接、采集时间

## 工作原理

- **双平台并行**：支持 BOSS直聘（zhipin.com）与实习僧（shixiseng.com），两平台可
  同时各自运行完整任务链（列表采集→JD补全），状态/闹钟/风控节奏/每日额度互不干扰；
  弹窗顶部切换平台，CSV 带"平台"列按平台独立导出
- **不碰加密 API**：BOSS/实习僧接口均有签名校验，插件改为解析浏览器渲染好的 DOM，行为上最接近真人
- **薪资字体解密**：定位加密字体优先读取薪资元素的计算字体 + `fonts.check` 验证码位覆盖；把加密字形画到 canvas 与参考模板（系统字体 + 自定义字体自带 ASCII 字形）做相似度匹配；用未分配码位生成豆腐块基准过滤缺字假模板；解密失败以 `□` 显式占位。实习僧列表页同用此引擎；实习僧详情页字段为明文，JD 补全时自动覆盖加密值
- **列表采集（闹钟驱动单步）**：滚动采集不在页面内自转，而是后台闹钟每步发一次
  "手势+抓取"指令——Service Worker 随便休眠、浏览器最小化、标签页隐藏都不会中断。
  这是实测修正：隐藏标签页中页面内定时器被 Chrome 节流到 ~1次/分且 scroll 事件
  永不触发（旧版因此假死在首屏几十条）；后台驱动的单步 + 合成 scroll 派发实测
  可持续加载
- **JD 获取（热标签页导航）**：BOSS 对每次程序化请求（fetch/iframe/新开冷标签页）都会重定向到 JS 安检页，原理上无法拿到 JD；插件复用用户已登录、有交互历史的标签页做真实导航（与手动点击行为一致，被动安检自动通过），导航进详情 → 提取 → 返回列表，逐条进行；若弹出滑块会提示人工完成，完成后自动继续
- **数据校验**：公司名串位检查、字段终验修复（HR 相关字段已移除）
- **任务抗中断**：运行状态与标签页 ID 持久化，Service Worker 被浏览器休眠重启后自动恢复现场；JD 补全与列表采集均为闹钟驱动单步状态机，心跳闹钟兑底拉链，浏览器重启自动续跑
- **提取健壮性**：JD 四层降级提取（容器拼接/选择器/关键词定位/大文本兑底），层间异常互不影响；内容脚本未注入时自动强制注入
- **搜索词队列**：后台维护 URL 队列，某搜索词采尽自动导航到下一个
- 数据实时持久化到 `chrome.storage.local`，刷新页面、重启浏览器均不丢失

## 二次开发

BOSS/实习僧会不定期改版，如采集失败按以下入口排查：

- **BOSS 列表选择器失效**：改 `content.js` 顶部 `SEL` 对象（每个字段支持多个备选选择器，按顺序尝试）
- **实习僧列表/详情选择器失效**：改 `content.js` 的 `SEL_SX` / `SEL_SX_DETAIL`
- **BOSS 详情页选择器失效**：改 `content.js` 的 `SEL_DETAIL`
- **字体解密阈值**：改 `content.js` 中 `FontDecoder` 的 `0.55 / 0.7` 相似度阈值
- **采集节奏**：改 `content.js` 顶部 `CONFIG`（翻页延时、滚动步进、超时等）

欢迎提交 Issue 反馈改版适配与 Bug，PR 前请先跑通一次完整采集流程。

## 常见问题

**Q：设了 1000 条但只采到 300 条？**
BOSS 单个搜索词最多返回约 300 条（10 页 × 30），平台限制且本插件严格忠于关键词自身检索结果。请在关键词框填多个关键词（逗号分隔）接力采集。

**Q：提示"未找到岗位列表"？**
确认已登录 BOSS，且页面是职位搜索结果页，不是职位详情页。

**Q：弹出滑块验证？**
在页面上手动完成验证即可，插件检测到验证消失后会自动继续。

**Q：想加快 JD 获取速度？**
JD详情采集为串行模式（模拟真人点击，一次一条），若中途弹出滑块验证请在当前标签页手动完成，完成后自动继续。

**Q：JD 字段为空？**
详情页请求偶尔被风控拦截（返回验证页），等一会儿点 **补全JD** 重试；若大面积为空说明账号/IP 被风控，建议降低频率、换时段再试。

**Q：薪资出现 □ 或数字不对？**
字体解密是启发式模板匹配，BOSS 更换字体后个别字形可能识别失败；可在 `FontDecoder` 中调整阈值或参考字体列表，导出前建议抽查几条与页面对照。

**Q：数据会丢吗？**
已采集数据实时存本地，点"清空"才会删除。
